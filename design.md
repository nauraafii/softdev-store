# Desain

- Gaya: brutalist, sudut tegas, garis hitam, tanpa gradient atau dekorasi tambahan.
- Warna: putih tulang `#f1eee5`, hitam `#191916`, merah bata `#a6402d` untuk aksi dan penanda.
- Tipografi: Impact untuk judul katalog; Arial untuk produk; Consolas/Courier New untuk label.
- Grid: empat kolom desktop, tiga tablet, dua ponsel; harga panjang harus tetap terbaca.
- Interaksi: fokus keyboard terlihat, tombol ikon memiliki nama aksesibel, dialog keranjang dapat ditutup dengan Escape/tombol/backdrop.
- Status: loading, error dengan coba lagi, hasil kosong, dan keranjang kosong harus ditampilkan dengan jelas.
- Hormati `prefers-reduced-motion`; gunakan gambar produk dari API.
